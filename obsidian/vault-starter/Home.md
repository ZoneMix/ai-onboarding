# Home

| Folder | What goes there |
|---|---|
| [[0_MEMORY/README\|0_MEMORY]] | Long-term memory every agent loads first |
| `1_AREAS` | Ongoing areas of life or work, one folder each |
| `2_STUDY` | Courses, certifications, study notes |
| `3_READING` | Books and articles, with highlights |
| `7_PROJECTS` | Things with an end: one folder or note per project |
| `8_DAILY` | Daily notes, `YYYY-MM-DD` |
| `9_OPERATIONS` | How things run: maps of content, runbooks, checklists |
| `10_IDEAS` | Loose ideas before they become projects |
| `99_OTHER` | Everything that doesn't fit yet |
| `People` | One card per person |
| `_obsidian` | Templates and attachments |
| `_agents` | The agents' own workspace: reports, feeds, queues, logs, project build trees. Not for reading. |

Rename and renumber freely; the numbers only keep the sidebar in a stable order.

Agents: read [[AGENTS]] first. Your own tracking goes in `_agents/`; notes here stay short and readable.
